# 🎮 Guild Glory Bot

Sab kuch ek hi file me combine kar diya gaya hai!

---

### 🚀 Bot Start Kaise Karein?

Aapko koi bhi alag-alag file ya setup chalane ki zaroorat nahi hai:
1. Bas folder me **`start.bat`** par double click karein.
2. Bot aur Dashboard automatically start ho jayenge aur browser me page open ho jayega:
   👉 **http://127.0.0.1:25086**

---

### 🛑 Bot Band Kaise Karein?
Jab bot band karna ho, bas us **black Command Prompt window ko close** kar dein (ya keyboard par `Ctrl + C` dabayein).
